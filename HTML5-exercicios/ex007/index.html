Negrito / Destaque

Nessa frase temos um termo em negrito usando a tag <B> (não semântica)

Nesta frase, tenho um termo em destaque usando a tag <strong> (semântica)

Itálico / Ênfase

Nesta frase, temos um termo em itálico usando a tag <i> (não semântico)

Nesta frase, temos um termo em ênfase usando a tag <em> (semântico)

Texto marcado

Podemos criar também um texto marcado usando a tag <mark> (sem semântica)

Texto grande e pequeno

Texto deletado

Podemos marcar um texto como excluído para indicar que ele deve ser lido, mas não considerado.
